# Style: Handwritten

> **Standards vs style:** this style may override house-style defaults (canvas, type scale, grid, accent); it never overrides the universal standards in `principles/restraint.md`.
> **Extension:** written for motomation-studio because the skill (v2.6.0) has no `handwritten.md`. Same format as `styles/minimal.md`, plus the fields the build brief asked for. Candidate to contribute back.

**Essence:** a person's hand on the page: ink, margins, notes.
**Use when:** journals, personal portfolios, teachers, small makers, letters.
**Avoid when:** dense product UI; any text that must read fast.

- **Type:** a script face for headings and notes only, a bookish serif for text.
- **Colour:** paper, blue-black ink, one red pen.
- **Layout:** a notebook page: margin rule, ruled lines, dated entries.
- **Motion:** Tier 1–2. Ink at a hand's pace; draw-on lines; nothing faster than writing.
- **Default dials:** Energy 1 · Rhythm 2 · Motion 2
- **Archetypes that suit it:** timeline, letter, index
- **Section order:** the page · the entries · the margin notes · the signature
- **Signature menu:** Thread, Typewriter, Remembered List
- **Must-haves:** script never below 20px; the visitor can write too
- **Pitfall:** script body copy and fake handwriting everywhere.
