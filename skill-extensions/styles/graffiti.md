# Style: Graffiti

> **Standards vs style:** this style may override house-style defaults (canvas, type scale, grid, accent); it never overrides the universal standards in `principles/restraint.md`.
> **Extension:** written for motomation-studio because the skill (v2.6.0) has no `graffiti.md`. Same format as `styles/minimal.md`, plus the fields the build brief asked for. Candidate to contribute back.

**Essence:** marks made by the visitor on a wall.
**Use when:** street culture, music, youth campaigns, events, activism.
**Avoid when:** institutional, legal, medical.

- **Type:** an ultra-heavy display face, a sturdy grotesk.
- **Colour:** night ground, a hot vermilion, chalk, signal yellow.
- **Layout:** a manifesto wall: one poster, one paintable surface.
- **Motion:** Tier 2. Spray, drips under gravity, a strip that skews with velocity.
- **Default dials:** Energy 3 · Rhythm 3 · Motion 2
- **Archetypes that suit it:** manifesto, poster, gallery-wall
- **Section order:** the wall · the poster · the tools · the strip
- **Signature menu:** Velocity Skew Marquee, Sticker Scatter, Pixel Wake
- **Must-haves:** spray never covers text that must be read; tools are buttons
- **Pitfall:** fake graffiti fonts slapped on a corporate grid.
