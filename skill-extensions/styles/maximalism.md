# Style: Maximalism

> **Standards vs style:** this style may override house-style defaults (canvas, type scale, grid, accent); it never overrides the universal standards in `principles/restraint.md`.
> **Extension:** written for motomation-studio because the skill (v2.6.0) has no `maximalism.md`. Same format as `styles/minimal.md`, plus the fields the build brief asked for. Candidate to contribute back.

**Essence:** more of everything, organised so the room still reads.
**Use when:** the brand is loud by nature: fashion drops, festivals, music, a collector's catalogue.
**Avoid when:** the visitor needs one answer fast, or the content is thin (maximalism exposes thin content).

- **Type:** two loud display faces at most, one disciplined text face; scale jumps of 3× or more.
- **Colour:** a saturated base with 2–3 clashing accents; one colour reserved for the thing to click.
- **Layout:** layered collage on a hidden grid; overlap allowed, reading order never broken.
- **Motion:** Tier 2. Things land and stay; hover reveals, no ambient loops.
- **Default dials:** Energy 3 · Rhythm 3 · Motion 2
- **Archetypes that suit it:** gallery-wall, lookbook, poster
- **Section order:** hero wall · featured pile · index of everything · colophon
- **Signature menu:** Sticker Scatter, Proximity Weight on one word, Image Trail
- **Must-haves:** a visible reading order through the noise; one quiet zone per screen; every object is content, not filler
- **Pitfall:** noise without hierarchy. If you cannot say where the eye lands first, cut a third.
