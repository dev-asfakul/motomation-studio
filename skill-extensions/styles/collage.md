# Style: Collage

> **Standards vs style:** this style may override house-style defaults (canvas, type scale, grid, accent); it never overrides the universal standards in `principles/restraint.md`.
> **Extension:** written for motomation-studio because the skill (v2.6.0) has no `collage.md`. Same format as `styles/minimal.md`, plus the fields the build brief asked for. Candidate to contribute back.

**Essence:** cut, torn, taped: pieces with real z-order.
**Use when:** zines, activism, music, arts organisations, personal sites.
**Avoid when:** checkout flows, data-heavy products.

- **Type:** mismatched faces drawn from the site's own set; one steady text face.
- **Colour:** paper neutrals, black, one tape colour.
- **Layout:** a letter or board: pieces on a surface, a receipt column beside it.
- **Motion:** Tier 1–2. Drag and drop; pieces tilt when held and land slightly off.
- **Default dials:** Energy 3 · Rhythm 3 · Motion 1
- **Archetypes that suit it:** letter, gallery-wall, index
- **Section order:** the note · the pieces · the receipt · the source list
- **Signature menu:** Brand Selection, Animated List, Sticker Scatter
- **Must-haves:** every piece draggable by keyboard too; torn edges that never clip text
- **Pitfall:** random rotated stock cut-outs.
