# Style: Futuristic

> **Standards vs style:** this style may override house-style defaults (canvas, type scale, grid, accent); it never overrides the universal standards in `principles/restraint.md`.
> **Extension:** written for motomation-studio because the skill (v2.6.0) has no `futuristic.md`. Same format as `styles/minimal.md`, plus the fields the build brief asked for. Candidate to contribute back.

**Essence:** data as space: volumes, rings and readouts.
**Use when:** research, space, hardware, data products, technical launches.
**Avoid when:** handmade or heritage brands; anything warm.

- **Type:** a monospace display face, a clean grotesk for annotations.
- **Colour:** cool dark ground, chalk ink, one blue for the active state.
- **Layout:** a field guide around a central volume.
- **Motion:** Tier 3–4. Weightless orbit with damping; slices glide; no auto-orbit.
- **Default dials:** Energy 3 · Rhythm 2 · Motion 3
- **Archetypes that suit it:** field-guide, stage, console
- **Section order:** the volume · the slice · the readout · the index
- **Signature menu:** Stacked Deck, Split-Flap, Orbiting Circles
- **Must-haves:** a designed poster for no-WebGL; readouts in real text
- **Pitfall:** spinning globes and neon gradients that mean nothing.
