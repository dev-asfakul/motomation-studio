# Style: Y2K

> **Standards vs style:** this style may override house-style defaults (canvas, type scale, grid, accent); it never overrides the universal standards in `principles/restraint.md`.
> **Extension:** written for motomation-studio because the skill (v2.6.0) has no `y2k.md`. Same format as `styles/minimal.md`, plus the fields the build brief asked for. Candidate to contribute back.

**Essence:** chrome, bubbles and operating-system nostalgia, used as an interface not a costume.
**Use when:** music, fashion, games, developer tools with a playful edge, anything with windows and drag.
**Avoid when:** formal or institutional work; long reading.

- **Type:** a wide or rounded display face, a monospace for system text.
- **Colour:** chrome gradients, icy blues and one hot accent; glossy highlights at 1px.
- **Layout:** a desktop: windows, docks, draggable panels with real content inside.
- **Motion:** Tier 2–4. Springy windows, chrome blobs, cursor sparkle used once.
- **Default dials:** Energy 3 · Rhythm 3 · Motion 3
- **Archetypes that suit it:** workbench, console, gallery-wall
- **Section order:** boot · desktop of windows · one open window per topic · shut down
- **Signature menu:** Neighbour Moves, Sticker Scatter, Click Spark
- **Must-haves:** windows that do something; keyboard access to every draggable thing
- **Pitfall:** nostalgia wallpaper with nothing to operate.
