# Skill extensions

Style files and data the build needed that the skill (asfakulsiam-motomation-design v2.6.0) does not ship. They follow the skill's own format so they can be contributed back. Nothing here pretends to be part of the skill; the site labels every exhibit that uses one as "extension".

- `styles/*.md`: 16 styles (maximalism, surreal, y2k, pixel-art, clay, cyberpunk, pop-art, retro, collage, vector-art, futuristic, handwritten, bohemian, graffiti, aurora, victorian).
- `data/fonts-addendum.csv`: faces used by exhibits that are not in the skill's `data/fonts.csv`.
